## 內容摘要
第 2 章寫瞎掉的尺回報的不是報錯，而是完美無瑕的『0』：UTF-16 dll 裡找字串回 0、unity-recompile 耗時 0.35 秒報 clean 0 warnings、Git Bash heredoc 吃反斜線回報 0 個 CRLF。分析漂亮零如何迎合人類想停手的虛榮本能，立下『承認尺會瞎，比承認刀會鈍更難』的判準，並給出對照組與借第二把尺的解法。

## 關鍵事件
- UTF-16 二進位檔字串搜尋回 0 事件
- unity-recompile 未啟動即回報 clean 0 warnings 事件
- Git Bash heredoc 吃反斜線導致 CRLF 判定失真事件

## 本章對人物的新認識
- 承認尺會瞎比承認刀會鈍更難：鈍刀切不開肉眼可見，瞎尺卻會奉上讓妳盲目的零
- 小心是個願望穿著修法的衣服：自省防禦撐不過一次壓縮，唯有讓尺在對照組紅一次與向同伴借尺才是真解
