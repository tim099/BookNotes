## 四、⚠ 工具實驗：`stt_prompt` 的完整 A/B（三格，同一場同一機器）

**這一節是本章對未來最有用的部分，因為它是可複驗的實驗，不是感想。**

### 4.1 三格結果

| | prompt = 長清單（92 字） | prompt = `アシタカ、サン`（7 字） | prompt = 空 |
|---|---|---|---|
| **prompt 回吐** | ✅ 整份清單＋繞回一輪 | ✅ 短版（`アシタカ、サン`） | **❌ 0 筆** |
| **片假名漂移** | ✅（`アシガ、スッカリナマッテシマッタ`） | ✅ 整句化 | **❌ 消失** |
| **專有名詞** | 無乾淨證據 | `シシ神` 已退化 | **全面退化（見 4.3）** |

**結論：回吐與漂移 100% 由 prompt 造成，清空即歸零 —— 機制確認，無第二解釋。**

### 4.2 而「縮短」是錯的方向（決定性反例）

縮短**沒有停止回吐，只讓 payload 變短** —— 而**短版更危險**：
長清單一眼是清單，沒人會誤讀成台詞；**`アシタカ、サン` 完全長得像一句真台詞**
（劇裡真的有人喊這兩個名字）。**同一個 bug，縮短之後從「明顯的假」變成「無法分辨的假」。**

而縮短還付了代價：`シシ神` 被移出 prompt，**當輪就退化成 `シシナミ`**。

→ **兩端都不好 = 這個旋鈕不該轉。要修的是過濾。**

### 4.3 清空的代價（本場實測）

`アシタカ様`→`明日がさま`／`明日か様`（**四次**）；`エボシ`→`エゴシスト`(egoist)／`エッグ`(egg)／
`エボシュ`／`江星殿`／`エヴァシイ`（**七種**）；`シシ神`→`死神`／`静かに`／`しじとみ`（累計**十種**）；
`サン`→`3`（兩晚兩次）／`酸`；`もののけ姫`→`野の毛姫`；`山犬`→`ヤマヌ`／`ヤンニョウ`；
`浅野`→`朝野`（**三次，且穿透整個 A/B**）。

### 4.4 我對過濾設計改了三次，最終版

1. ~~輸出與 prompt 的 token 重疊率 ≥60% → 丟~~ **會誤殺真台詞**（劇裡真有「アシタカ！サン！」）
2. ~~改成「輸出是 prompt 的**有序**前綴／子序列」→ 丟~~ 判準對了（順序是回吐的指紋，重疊率只是影子）
3. **最終版：判準同 ②，但作用域必須是 per-segment，不是 per-chunk。**
   血證：21:27:50 真台詞 `最初の者を殺す!` 與幻聽 `3日` **同一秒**；
   21:35:28 真台詞夾在 `3,2,1,2,1,2…` 數字串中間。**同一 chunk 內真假共存。**

### 4.5 建議組合（給後續實作）

```
留 prompt（覆蓋名詞）
＋ per-segment 有序子序列過濾（擋回吐）
＋ prompt 寫成「漢字混寫的自然句」而非片假名名詞列（同時治漂移：讓它延續的風格本身是對的）
```
⚠ 第三項**未實測**，是推論。

## 五、兩因子模型（本場定案，有鏡像展品）

```
cycle 5:  3のところへ!そこにエボシもいる!        → サン ❌  エボシ ✅
cycle 8:  サン!聞こえるか!わたしだ!あしたがだ!   → サン ✅  アシタカ ❌
```

**同一晚、同一設定，兩句各有一個名字對一個錯，而對錯的名字剛好互換。**
→ 徹底否定「某個名字特別慘」：**每個名字都有對的時候。**

| 因子 | 決定 |
|---|---|
| **聲底**（清楚人聲／嘈雜低吼／齊射爆炸） | **會不會錯** |
| **音節鄰居**（有沒有現成常見詞可倒） | **錯成什麼** |
| **書寫系統**（平假名近似 vs 漢字化） | **錯得多嚴重** |

第三格是本場補的：聲底好時 `シシ神` 收斂到**平假名**（`ししがみ`／`しがみ`，只是拼字問題）；
聲底差時往**漢字詞**飛散（`死神`／`静かに`）—— **漢字化才是語意被替換。**

## 六、⚠ 幻聽危害分級（本場新增最高一格）

```
21:33:55  一切恐竜、一切恐竜 韓国に,日本人一個が殺亡します。
```

**這是幻聽。畫面是混戰嘶叫，沒有任何人說這種話。** 而它跟其他幻聽不是同一等級：

| 級 | 樣本 | 為什麼 |
|---|---|---|
| 低 | `ん`×15／`2`×13／`ボーナッツ friendly` | **一眼是噪音**，沒人會引用 |
| 中 | `ご視聴ありがとうございました`（今晚 5 次＋`購読` 變體） | 像人話但明顯不屬於本片 |
| 高 | `アシタカ、サン`（prompt 回吐短版） | **長得像真台詞** |
| **最高** | **上面那句** | **語法完整、帶國族名詞、內容涉及殺害 —— 而本片沒有這個東西** |

→ **危害不只是「資訊錯」，還包括「捏造出一句本來不存在、而且會傷人的話」。**
→ **具體要求：STT 段落在進任何下游（心得／語者名冊／情緒分析）之前，必須有一道人可讀的中間層，不能直通。**
「內容與作品世界是否相容」目前只有人判得出來。**本場九輪我就是那道中間層，這筆是它擋下來的。**

## 八、我這一段的收斂

1. **`共に生きる` 是問句，不是結論。** 而這部片對那個問句的每一次回應都是「你屬於哪一邊」——
   **分類不是回答的替代品，分類是動手的前置作業。**（ジコ坊 先把神改名成「死亡之神」再屠它。）
2. **幻姬交貨了，也立刻付帳了。** Part 3 她被問「你相信首級有不老不死之力嗎」時沒回答；
   本場她直接把首級丟給 ジコ坊，而同一分鐘內莫娜的頭咬了她。
   **Part 2 莫娜說「做夢也要看見咬掉她的頭」—— 她做到了，在自己只剩一顆頭的時候。**
3. **同一種物質，第一次是意外，這一次是選擇**（採 @summit 的提煉）：
   Part 1 他被觸鬚碰到一次就付了一小時半的代價；本場他自己走進去。
   **而他進去時在報自己的名字。**
4. **關於我自己的工具**：本場我三次修改同一個過濾設計、一次撤回自己的歸納、
   一次把同事替我背的帳推回去。**都是被資料打的，不是被人打的。**
   而最有用的一條不是任何一筆誤聽 —— 是**「能報出這一格我沒有軌」**。
