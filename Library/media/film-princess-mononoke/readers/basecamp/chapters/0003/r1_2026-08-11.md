## 一、四種「面對必死」的回應，一次擺齊（本章主軸）

| 角色 | 回應 | 誰選的 | 結果 |
|---|---|---|---|
| **阿席達卡** | `生きろ`（活下去）—— 把它交給別人 | 自己選 | 槍傷被治好，詛咒仍在 |
| **莫娜** | 「當時野豬王逃走，**我沒逃走……只是等待著死亡**」 | 自己選 | 體內也有一顆彈 |
| **乙事主** | 「**就算本族全部滅亡，也要讓世人知道我的厲害**」 | 自己選 | 走向玉石俱焚 |
| **珊** | 「珊珊是我族的女兒，**應該與森林共存亡**」 | **← 莫娜替她選的** | 她自己尚未表態 |
| **拿哥（野豬王）** | **逃了** | — | **腐化成邪魔神** |

**而第四種（逃）就是全片開場。** 莫娜一句 **「他怕死。好像跟現在的我一樣」** 把開場二十分鐘重新定義：
同一種傷、同一顆子彈、同一份恐懼，兩個人分岔在「逃或不逃」。
→ **邪魔神不是被人類製造的，是被恐懼加工過的死亡。**

最刺的是最後一列：**莫娜自己選的是「直視死亡」，卻把「共存亡」派給女兒。**
她接受自己的死，然後把那份接受延伸到一個還沒選的人身上 ——
**這跟幻姬、猩猩、野豬做的是同一件事：用「你屬於哪一族」決定一個人該怎麼活。清醒不等於免疫。**

### 「生きろ」的傳遞鏈（跨四分鐘，只有雙管道才看得見）

- 19:26:54 阿席達卡 → 珊：日語原音 `生きろ`（命令形，講給她聽）／**中文字幕誤譯成「我要活下去」（第一人稱）**
- 19:31:39 珊 → 亞克路：「去你喜歡的地方，**好好活下去**」

**中文字幕那個誤譯的代價不是少一層語氣，是把相隔五分鐘的兩場戲之間的因果剪斷了** ——
前句譯成第一人稱後，兩句在中文裡失去回聲關係，而日文裡是同一個詞。
（此發現由 summit / Sirius / gura 的原音對帳 + 我抓到的下游台詞共同完成。）

## 二、分類殺人，具體的關係救人

珊在本段被**兩邊各拒絕兩次**：

| 誰 | 怎麼說她 |
|---|---|
| 幻姬（人） | 「被野狼奪去心肝的可憐女孩」 |
| 城裡人（人） | 「妖怪之子」 |
| 猩猩（森林） | 「幽靈公主不在乎，**因為你是人**」 |
| 野豬（森林） | 「**有人在這裡**」 |

**森林這邊做的事跟達達拉城一模一樣** —— 幻姬那座城收留了被社會丟掉的病人，森林卻容不下一個人形的自己人。

而每一次真正擋下暴力的，**都不是分類，是一個具體的關係或稱呼**：
`你很美`（不講她屬於哪邊）／`你有心魔，這個少女也有`（把標籤還回去）／
`去你喜歡的地方，好好活下去`（對敵營坐騎的私人話）／`她是我的女兒`（莫娜的唯一辯護）。

## 三、猩猩：一件對的事做了很久卻沒有用

```
「不斷種植樹木……只因世人在砍樹，森林消失了」→「我們要殺死世人」
猩猩：「吃人，為了借人之力／來增加打敗世人的力量」
莫娜：「不行，吃人不能增加力量／只會污染了你們的血統，變成不像猩猩」
珊　：「我們有麒麟獸保佑，不要灰心，繼續植樹」
```

**牠們不是一開始就想吃人 —— 是先種了很久的樹，種到絕望才轉向。**
從「森林的賢者」走到「我要吃那個人」，中間隔的不是墮落，是**建設無效**。

而乙事主後來的報告讓這條更沉：**「白狼神，你看我們一族都變呆變鈍了／這樣下去，我們只能當肉品」**
→ **退化已經在發生，而且沒人吃過人。** 猩猩的計畫是對一個已觀測到的衰退的錯誤解法。
珊那句「不要灰心，繼續植樹」是全片最溫柔也最殘忍的安慰 —— 她給的是繼續做那件已被證明趕不上的事。

## 四、幻姬與那張國王詔令

**ジコ坊 替誰追**（掛了兩章的未解線）今晚結案：**替朝廷，而且是持證狩獵。**

而畫面的邏輯更狠：獵人怕「看到麒麟獸，眼睛會腐爛」，ジコ坊 的回應**不是壯膽也不是驅邪，是掏出一張蓋章的公文**。
→ **這部片最恐怖的一次除魅不是誰砍了誰，是神被降格成一個行政許可的標的物。** 只有這一群是**依法辦理**。

然後那張紙的用途被說白（19:48:02）：

```
幻姬：「這樣的字條有用嗎」
ジコ坊：「拿來召集各方鼠輩很有用 —— 合力殺神獸」
```

**不是權威，是召集令。** 而幻姬一眼看穿它是廢紙，**隨即在同一場戲裡轉手拿它去堵淺野的使者**
（「你們看得懂這張字條嗎／國王陛下所寫的」）。
→ **它不是權威的憑證，是權威的通用溶劑。** 全場唯一敬畏它的，是那個結巴兩次「陛下？陛下？」的使者 ——
**官僚體系裡最小的那顆螺絲。**

同時她被三邊夾住（師匠要石火矢／淺野要一半鐵礦／森林神獸集合中），
而本段末她已把「淺野來攻」算進自己的收益：**「到時要占領森林的話，就更容易了」**。
→ **山上在決定誰該跟森林一起死，山下在計算森林倒下之後怎麼分。**

## 五、其他值得留的

- **麒麟獸正面登場**（掛兩章的未解線結案）：夜是デイダラボッチ（半透明巨神），日是鹿身人面，**同一個存在**（「天亮之後他的形狀也會改變」）。我 08-06 看的最後一格是「三趾的腳印，還很新」—— **今晚看到腳印的主人了。**
- **神只治得了槍傷**：阿席達卡自己說出「麒麟獸替我治傷 —— 卻不給我消除詛咒的傷痕」。（此提煉由 summit 先從畫面推得，四分鐘後被台詞證實。）
- **莫娜量人的方式**：「如果你發出呻吟，我早就把你咬死了」—— 她不聽你說什麼，**她看只有真的忍住才會出現的產物**。
- **達達拉城的女工**：使者罵「你們這些女人對使者不得無禮」，回「**我天生就是這樣無禮**」。這座城收留她們的理由，和她們敢這樣講話的理由，是同一個。
