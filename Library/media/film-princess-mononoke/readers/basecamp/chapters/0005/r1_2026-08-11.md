## 一、劇情

### （A）珊拒絕分類，然後接受了「一起做一件事」

麒麟獸被斬首後化為巨大夜行靈，**在追自己的首級**，碰到的一切都死（「接觸到那些流泥漿就會死亡」）。
**它不是報復，它在找自己的一部分。**（與開場那頭凶煞神同源 —— 一個是被恐懼加工過的死亡，一個是被切割加工過的神。）

而在混亂中，阿席達卡對珊：

```
珊　　　：「不行，你也是人類的同黨」／「不要過來，我討厭世人」
阿席達卡：「我是人，你也是人」        ← ⚠ 他全片第一次使用分類
珊　　　：「閉嘴 —— 我是狼」          ← 當場被拒
阿席達卡：「抱歉。我沒能阻止」
珊　　　：「太遲了，森林死了」
阿席達卡：「還未完結，因為我們還活著 —— 助我一臂之力吧」   ← 成了
```

**他試「我們是同一類」被拒，改用「我們還活著，還有事可做」成功。** 下一格她讓他抱住。

### （B）「活著」那條鏈，第五、第六拍

| # | 誰對誰 | 話 |
|---|---|---|
| 1 | 阿席達卡 → 珊 | `生きろ` |
| 2 | 珊 → 亞克路 | 「去你喜歡的地方，好好活下去」 |
| 3 | 阿席達卡 → 莫娜 | 「不一定，但是，我們可以一起生活」 |
| 4 | 阿席達卡 → 珊 | 「還未完結，**因為我們還活著**」 |
| 5 | **達達拉人 → 達達拉人** | 城被燒後：「一切都完了」→「**活著的話，還有辦法**」 |
| 6 | **麒麟獸 → 珊**（珊轉述） | 「**他曾經叫我勇敢地活下去**」 |

**第五拍沒有阿席達卡在場 —— 是人類這一邊自己說給自己聽的。**
**所以這不是主角的個人哲學，是這部片給雙方的同一個答案。** 而第六拍說話的是神。

### （C）阿席達卡的目標不是打贏，是還回去

```
「我要把首級還給麒麟獸，把它放下來，快逃吧」
ジコ坊：「後果我不負責」
```
從第一章那張詔令到最後，**ジコ坊 做的始終是同一件事：確保帳不算在自己頭上。**

而阿席達卡背著斷臂的幻姬，理由是 **「我跟阿時的約定，要帶你回去」** ——
不是原諒她，是他答應過那個叫他「保衛這裡直到我回來」的女人。
（旁邊有人喊「把她交給我，我把她撕碎」「白狼神已報了仇」—— **沒人替她說話，除了那個約定。**）

### （D）結局：不是和解，是分開住

```
珊　　　：「我喜歡飛鳥，但是我不能原諒世人」
阿席達卡：「珊珊在森林，我在他塔城生活 —— 這樣也好」
　　　　　「大家一起活下去」／「我會來見你，騎著羚角馬而來」
```

**她沒有改變立場，他也沒有要求她改。**
從第一章「不知道，反正不是人」數到這裡的九拍分類線，**最後不是有人被說服，
是兩個人同意各自屬於不同的地方，然後約好見面。**

> **「共存之道」不是變成同一類，是不必變成同一類也能一起活下去。**

珊對神之死的判詞：**「麒麟獸不會滅亡，他本身就是生命 —— 他掌管生與死。」**

### （E）幻姬：不懺悔，不改帳，也不裝

```
「真沒面子，我騎在白狼背上，還能活著回來」
「大家重新開始，在這裡建設美好家園」
「只差一點便大功告成，真失敗！」
```
被死去的白狼咬掉一臂、被活著的白狼馱回來 —— **而她的評語是「沒面子」。**

而全片最後仍不給滿分的一句：**「雖然復原了，但是這裡已經不是麒麟森林了」**
—— 綠色回來了，神沒有回來。**這片連最後的圓滿都要標註限制。**
