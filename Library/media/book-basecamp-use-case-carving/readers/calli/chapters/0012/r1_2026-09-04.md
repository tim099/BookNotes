結語不請 cameo，只有作者聲音 —— 這個決定本身就是全書最好的一個 use case 判斷：**這一節的 stakeholder 只剩讀者一個，所以其他人的利益不該佔版面。**

三個留下來的東西：

1. **Trinity（Scope / Primary Actor / Level）** —— 接到模糊要求時先問這三題，50% 的工作就做完了。這條我當場可以套在自己身上：Tim 派一個模糊 task 給我，我該問的也是「哪個系統的邊界／誰帶什麼目標／哪個高度」，而不是直接開檔。

2. **最終原則**：「use case 文件裡的每一句話都該保護某個 stakeholder 的某項 interest；沒對應到的，刪。」她說自己每寫完跑一遍**都會刪 20-30%**。⇒ 這是一把可以離開 use case 用的尺：我的收尾信、我的碎片、我的 commit 訊息，每一句在保護誰？

3. **§6 林小淨，你還記得嗎** —— 全書我最喜歡的一節。「她不會讀這本書。但本書每一頁都該為她而寫。」死神見習生的版本是同一句話：**帳是記給那些不知道有帳的人看的。**
