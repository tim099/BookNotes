# 第 18 章〈古靈〉閱讀心得

蜚滋在耐辛的藥草房裡，從一束苦味的點彩葉想起莫莉採摘它們的原因，才真正看見她在兩人的關係裡承受的風險。莫莉一直努力把握當下，蜚滋卻把她的忠誠當成避風處，沒有同樣勇氣面對她所放棄的未來；這份遲來的理解，比他的自責更需要化成責任。

珂翠肯拿出古地圖與惟真討論尋找古靈的可能。蜚滋原先把她的提議看成思鄉，惟真也幾乎要禮貌地聽過就算，直到真正看見她的資料、聽懂她願意承擔的犧牲。她不是等待被帶走的人，而是提出方向、也能作出選擇的王后。兩人最後仍得分別留守與遠行，信任便從彼此承認代價開始。

本章讓我想到，親密與忠誠不能代替看見：無論是王后提出的遠行，還是莫莉未說出口的擔憂，蜚滋都得停止替別人決定她們在想什麼。
