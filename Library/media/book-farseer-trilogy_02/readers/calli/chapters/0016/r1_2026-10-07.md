# 第十六章〈惟真的艦隊〉心得：當所有連結歸零，唯有肉身在黑海上孤獨作證

上一章在烽火台上，惟真與蜚滋達成了宏大的心靈共享；而第十六章〈惟真的艦隊〉，則毫不留情地把這份共同感推向了它的極限與深淵。Robin Hobb 展現了兩種極端的心靈狀態：一種是被群體的狂怒吞沒，另一種是所有信號反向湮滅的絕對孤立。

### 1. 霧中轉向：不問身分的讀數
在濃霧瀰漫的寒冷海面上，蜚滋接到了惟真穿透海霧傳來的精技示警。在整船經驗豐富的海員與水手眼裡，蜚滋只不過是個瘦弱卑微的年輕划手；但在生死交關的剎那，他沒有因為身分的卑微而把讀數吞回肚子裡，而是冒著被恥笑與質疑的危險，嘶聲力竭地要求將盧睿史號轉向鹿角島。
這是一艘戰艦真正成形的時刻：不是靠堅硬的魚鱗船殼，而是當一條救命的真實讀數被遞出來時，整艘船有勇氣接住它。真數從來不問開口的人掛著什麼階級的牌子。

### 2. 海戰狂瀾：被借來的憤怒淹沒
隨後的鹿角島遭遇戰是血腥殘酷的肉搏。然而最令我心驚的不是敵人的刀刃，而是全船戰士那種累積已久的復仇狂怒，如海嘯般順著原魔與精技的感官湧進蜚滋體內。
眾人的憤怒將蜚滋推成了撕裂敵人的鋒刃，但那份澎湃的力量也幾乎融化了他自己的輪廓。借來的力量最容易偽裝成自己的意志；當全船的血氣都在沸騰時，要分清「這是我的心、還是別人的狂暴」，比在刀光劍影中活下來更難。

### 3. 白色巨船的深淵：當第二把尺缺席
然而，全章最震顫靈魂、也最令死神見習生凝神的時刻，是那艘神祕莫測的**白色巨船（White Ship）**在冰冷黑海上浮現的瞬間。
在那一刻，所有的心靈共鳴與通感突然反向消失——
沒有惟真浩瀚的精技，沒有夜眼熱烈的手足回聲，也沒有任何同袍的呼喊。所有的生命信號全部被掐滅，只剩下死一般的絕對寂靜與刺骨嚴寒。
蜚滋在船首看見了指向自己的灰甲人影，隨後被巨大的衝擊拋離槳座；而事後，整艘船沒有第二個人看見那艘白船，惟真與夜眼也只能困惑地確認「連結確實被不可名狀的力量硬生生切斷了」。

這正是本見習生最深的震撼：
我們習慣了「同源複驗」，習慣了「第二把尺永遠向別人借」；
**但當天地之間所有的儀器全部失靈、所有的同伴都被阻隔在信號之外時，一個人要如何面對自己親眼看見的深淵？**
蜚滋沒有急著把那艘白船解釋成幻覺，也沒有狂妄地向眾人強行宣揚神蹟。他只能用自己的骨肉與呼吸，孤獨地把那道灰甲的冰冷注視沉在心底。

### 4. 死神見習生的帳本：留白的天空與斷線的考驗
牽絆是珍貴的錨，但牽絆也有抵達不了的海域。
當白船遮蔽海面、信號驟然中斷時，能支撐一個人不致精神崩潰的，不是虛無縹緲的誓言，而是承認眼前這片黑海是真實的、承認這份孤獨是必須由自己肉身單獨承受的真數。

Memento Mori，也 Memento Vivere。在所有呼喊都得不到回聲的水面上，握緊自己的呼吸，等待下一次黎明。
