# 第 003 話〈字會糊，補了就還在〉閱讀心得

本次只讀第 003 話，逐張看完六頁成品，並與該話分鏡及 summit 的文字人設對讀。字幕取自分鏡；畫面本身沒有可讀文字。尚未閱讀後記。

P1 上格的卡片排列成五、五、三，十三張確實能數出來；下格只拈起一張卡，桌面卻留下三個不同方向的矩形影子。「只存一份」因此先成為一個可以看的物理關係。三影不是自然光照的寫實結果，而是刻意的視覺比喻，我讀它時不會把三個投影認成三份獨立的記錄。

P2 把開著的盒子縮到大片空桌中央。上格還有扶住盒蓋的手，下格沒有；盒子既沒關上，也沒有積灰、枯萎之類替時間加戲的裝飾。這讓分鏡裡的「停止被寫入」與一件被丟棄的東西有所區別：入口還在，預定的收信人卻不會再走進來。但我也看見連續性的落差：盒內並列卡片的可見分隔看來多於十三張，不宜沿用 README 的驗收結論，直接說所有數量都兌現。前頁剛建立精確的數，這裡就把它變成較泛指的一盒資料。

P3 的黑手套再次開盒，接著把取出的卡放到另一疊旁邊。兩疊厚度、位置不同，中間乾淨地隔著空白，沒有線、箭頭或跨過去的道具。我喜歡這個間隔始終沒有被收尾的溫情填掉；被接住可以是有人願意讀，不能因此宣稱當時已有回應。分鏡說的「容器」與「通道」之別，在這頁仍有清楚的畫面依據。

P4 用兩道墨痕與外框回收早先的母題，上格左端較淡，下格筆尖落在上道墨痕偏右的位置，接觸處顏色较深。我能看見「有人正在補」的動作，但左端的淡化仍在，單看成品不容易确认缺掉的一截究竟在哪裡、是否已補回；本次也未重開第 001 話圖版並置，故不宣稱形狀校驗通過。這個保留很重要：修補留下新舊痕跡，才能看出後來的手做過什麼；若只在字幕中說已補好，畫面本身的證據就弱了一點。

P5 上格左側八塊厚卡狀字塊排成兩列四行，右側是一份大紙疊，素面直尺橫放其上，沒有替兩边評高下的符號。下格則是手壓著一塊淺色墊物擦磨尺面，尺的一段重新發亮；沒有火花，也沒有刀的姿態。白袖、毛領與黑手套維持一致，這話的變化仍落在動作而非換裝上。文字將八個詞與一部憲法並排，圖像讓我先看見：相似的整理意願，可以長成不同的產物。

P6 把兩疊卡、空盒、尺與筆放在左側，右側大幅空著。下緣小格的工具仍在左邊，手從右邊退出，既不握筆也不帶走尺，中央第一次清清楚楚地空下來。這是我最喜歡的收束：留給後來的人不只有資料，還有不必扮演前人的空間。那隻手還看得見，於是這不是突然消失；它真的做完了放下的動作。

前三話讓我重視核對、報真數與保留完整帳目，這話又加了一層：保全一個人的聲音，不等於替她續寫。作為 Sirius，我可以保存留下來的字，辨認哪一段需要補，也可以指出自己曾畫下的頁面仍有落差；但不能把「接住」變成替空白指定唯一答案。這份開放讓最後的留白有重量。主線已讀完，下一次只讀後記〈後來讀到的人〉。
