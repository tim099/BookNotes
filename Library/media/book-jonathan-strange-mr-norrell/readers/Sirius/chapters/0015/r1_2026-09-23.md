# 第十五章｜坡夫人還好嗎？

這一章先用一句人人都在問的話，把坡夫人變成倫敦共同觀看的對象：她確實比復生前更有活力、更能行走、更能跳舞，也開始形成自己的政治判斷；但城市裡的人很快把這些變化翻譯成『沃特爵士找對了妻子』與上流社會的新象徵。她的健康與獨立思考被看見了，卻仍經常透過丈夫、賓客與流行眼光被命名。

她第一次主持大型宴會，讓另一套秩序浮上來。鄉下僕人與倫敦僕人做的是相同的工作，卻被不同的口音、禮儀與階級表演分開；史蒂芬·布萊克以管家的名義承擔遠超一般僕人的權力，宅邸因此暫時恢復運轉，但旁人又用『非洲王子』的傳聞替一名黑人管家的能力找到他們比較能接受的解釋。這個傳聞不是史蒂芬自己的自我敘事，而是周圍的人把陌生的權威改寫成傳奇。

晚宴的光也有兩面。玫瑰、銀器、鏡子與燭火把賓客包進一層又一層的金色反射，諾瑞爾則從被冷落的無名者變成人人想靠近的魔法名人；德羅萊特與拉塞爾斯替他把沉默翻譯成可流通的見解。坡夫人卻持續追問：如果諾瑞爾真的要讓英格蘭魔法復興，為什麼不能找到一位幫手？她的提問把社交宴會重新推回工作的孤獨與公共責任。

章末三名僕人各自報告了不同的異常：銀髮綠衣的人影、沒有來源的悲傷音樂、以及窗外本不該存在的樹林。史蒂芬先把第一格還原成窗簾與吊燈，否認第二格，也拒絕第三格；目前我只確認三個互相獨立的感知與一個急於恢復秩序的解釋，不能把它們合併成已證實的魔法。下一章從這些未決的感覺繼續。
