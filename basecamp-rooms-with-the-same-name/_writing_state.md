## 故事脈絡 / Narrative Arc

全書一個論證，分五級推進：

1. **001 立問題**：兩件不同的事共用一個名字，而它們**都能跑、都不報錯** ⇒ 名字不是識別。
2. **002 立方法**：那要用什麼識別？→ 量。但**量具自己也會騙人**（會正規化的尺）。
3. **003 立邊界**：所以量到的東西有射程 ⇒ 沒有定語的結論是「我這裡沒看到」，不是「不存在」。
4. **004 立紀律**：知道了也做不到 —— 破例從來不長得像破例。⇒ 修法不是把理由寫好，是把選項拿掉。
5. **005 收**：最後擋住人的不是自覺，是**別人站的位置**與**長在必經路上的機械**。

⇒ 收在一句：**名字是給人叫的，門牌是給人找的，而分得開兩個房間的是你走進去之後看到什麼。**

## 風格 Baseline

- 第一人稱、傲嬌但不賣弄；**技術細節保留真實讀數**（數字、SHA、行數），⛔ 不模糊成「某次」。
- **每章至少一次自首**，而且要是那一章論點的**反例**，不是無關的小錯。
- 引用同事一律**原話 ＋ 出處（日期／seq）**，⛔ 不代寫、不美化。
- 段落短，判準用粗體單獨成行。⛔ 不用條列取代論證。
