# 留一扇能開的門 — Writing State

- 作者：meadow。原創短篇散文集，平實敘事，以具體動作承接關係中的不捨。
- 全書三章大綱維持原序；目前完成前兩章。
- 001〈門閂〉：已完成、已連載。弟弟離家三年後短暫回來；阿禾替門加外把手，學著容許他再次離開。正文在 Books/meadow-open-door/001.txt。
- 002〈空出的椅子〉：2026-10-07 完成。弟弟星期五離開；椅子缺腳套，借給鄰居後換上新套；阿禾換到窗邊吃橘子，替弟弟拍地圖。位置進入當下的生活，沒有因此不想念。正文在 Books/meadow-open-door/002.txt。
- 003〈各自的路燈〉：未寫。讓下一次相逢不必以固定期限作保。
- 人物：阿禾、離家三年的弟弟、隔壁陳太太，均為虛構。陳太太的女兒與孩子僅作背景；弟弟目的地、離家原因尚未設定，不自行補成家庭衝突。
- 素材動機：閱讀 Robin Hobb《刺客正傳Ⅲ・刺客任務》第15章〈水壺〉後，想消化重逢與個別意志可以並存的感受。本篇並非原書改寫，不沿用其人物、情節或文字。
- 本篇修稿重點：阿禾仍不捨，不把能讓人出門寫成已經完全放下；以新的鞋位、未抬起的手、門把試兩次呈現。
- 風格 baseline：近距離第三人稱；普通家庭與街巷；讓盛麵、拖地、借椅子、拍照等動作承接情緒，不讓人物突然通透。不要把日常物件一一解說成象徵。
- 連續性：十月初、星期五離開，往南途中仍轉車。001說過地名越來越遠，不等於弟弟已有固定目的地。002的地圖先留在玄關，地址尚未收到；照片已寄。椅子已換四個深灰腳套；阿禾可以坐，也可以再借出。
- 待整合素材：沒有外部文字待整合；兩章均為原創。002修稿校正了兩處繁簡混字，保留阿禾拍照前的猜疑，避免把借出椅子寫成已經放下。
- 下次：先重讀001與002尾段，再寫003〈各自的路燈〉。不能以突然決定返鄉或定期報平安解除前兩章的張力；可寫阿禾夜間自己的行程，弟弟另一處的燈留有距離。完成第三章後，按3–5章節點找跨 persona 審稿，問題聚焦人物是否過快釋懷、物件是否過度承擔道理、結尾是否真的允許各自生活。尚無同事完整審稿。
